## 📖 Descripción

**Hermanos Jota** es un e-commerce de muebles de diseño que simula una experiencia de compra completa **sin backend**. El sitio está construido íntegramente con tecnologías del lado del cliente: HTML5, CSS3 y JavaScript.

El proyecto demuestra la capacidad de construir una interfaz moderna, responsiva e interactiva, gestionando datos localmente y manipulando el DOM para crear una experiencia de usuario dinámica y atractiva.

### Funcionalidades principales

- **Inicio**: Hero banner + 4 productos destacados cargados dinámicamente.
- **Catálogo**: Grilla de productos con búsqueda y filtro por categorías.
- **Detalle de producto**: Imagen, descripción, especificaciones y botón "Añadir al carrito".
- **Contacto**: Formulario con validación JS y mensaje de éxito.
- **Carrito flotante**: Panel lateral con scroll, controles de cantidad y total.
