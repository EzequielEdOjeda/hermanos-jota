# Hermanos Jota — Cliente (React + Vite)

Este es el frontend del proyecto **Hermanos Jota**. Consume la API REST ubicada en `/backend`.

Para las instrucciones completas de instalación, ejecución y la documentación de arquitectura del proyecto completo, ver el [README principal](../README.md) en la raíz del repositorio.

## Comandos rápidos

```bash
npm install
cp .env.example .env   # define VITE_API_URL
npm run dev            # http://localhost:5173
npm run build           # build de producción en dist/
npm run preview         # sirve el build de producción
```
